# 佩剑体能训练 · 循环训练

基于训练计划《佩剑体能训练 · 循环训练周期计划》制作的安卓端训练小软件(PWA 渐进式网页应用)。

- 每日 30–60 分钟 · 循环训练 · 4 周一循环
- 佩剑(Sabre)专项定制:下肢冲刺爆发、腕臂挥砍、核心旋转、无氧耐力

## 功能

| 模块 | 说明 |
|------|------|
| **今日** | 按星期自动推荐当天模块(周一 A 爆发 / 周二 C 无氧 / 周三 B 腕臂 / 周四主动恢复 / 周五 D 核心 / 周六 A·C 加强 / 周日休息),一键开练 |
| **循环计时器** | 自动按当前周期周生成流程:准备 → 热身 → 动作 × 轮数(组间休息)→ 冷身 → 完成;支持暂停/继续/跳过、提示音、可选中文语音播报、屏幕常亮 |
| **周计划** | 一周 7 天训练安排,点按任意一天直接开练 |
| **动作库** | 4 大模块 24 个动作,含要点与进阶提示 |
| **4 周循环** | 基础适应 → 容量提升 → 强度冲刺 → 减量恢复,自动计算当前周(可设循环起点) |
| **训练记录** | 自动保存每次训练(轮数/时长/30 秒劈砍次数/备注),本周统计与连续天数 |
| **保底训练** | 实在没时间:10 分钟弓步步伐 + 5 分钟空击劈砍 + 5 分钟核心 |

## 30 / 60 分钟版本

| | 30 分钟版 | 60 分钟版 |
|---|---|---|
| 热身 | 5 分钟(4 步) | 8 分钟(5 步) |
| 主训练 | 5 个关键动作 × 2 轮 | 6 个动作 × 本周轮数(3–4 轮) |
| 冷身 | 3 分钟 | 8 分钟 |

工作/休息时长随周期周自动变化:第 1 周 30s:45s → 第 2 周 30s:30s → 第 3 周 40s:20s → 第 4 周 20s:40s。

## 安装到安卓手机(作为 App 使用)

本应用是 PWA,无需应用商店,安装后全屏运行、离线可用、有独立图标,体验与原生 App 一致:

1. 把 `sabre-training-app` 文件夹部署到任意静态服务器(或局域网主机上运行 `python -m http.server 8642`)。
2. 手机与电脑同一 Wi-Fi,用 **Chrome 浏览器**打开 `http://<电脑IP>:8642`。
3. 打开后点浏览器右上角 **⋮ 菜单 →「安装应用」(或「添加到主屏幕」)**。
4. 桌面出现「佩剑体能」图标,点开即为全屏独立 App,可离线使用。

> 也可直接用电脑浏览器打开使用(适配桌面布局)。

## 使用要点

- 首次打开在 **设置(右上角齿轮)** 里确认循环起点日期(默认当天);设置里可切换 30/60 分钟版、提示音、语音播报。
- 计时器中:⏸ 暂停/继续,⏭ 跳过当前阶段,**退出按钮需在 4 秒内连按两次**(防误触)。
- 每次完成训练后弹窗可填「30 秒劈砍次数」和「负重/箱高备注」,用于下一循环加量决策(对应计划文档的"自查与记录")。

## 文件结构

```
sabre-training-app/
├── index.html            # 主页面(5 视图 + 计时器)
├── css/style.css         # 样式(暗色剑道 + 金色主题)
├── js/data.js            # 训练计划数据模型(模块/动作/周期/热身冷身)
├── js/timer.js           # 循环计时器引擎(流程生成/提示音/语音/常亮)
├── js/app.js             # 视图渲染与交互逻辑
├── manifest.webmanifest  # PWA 配置
├── sw.js                 # 离线缓存 Service Worker
├── icons/                # 应用图标(192/512/maskable)
├── icons.js              # 图标生成脚本(需 npm i sharp)
└── README.md
```

## 开发

- 训练数据全部在 `js/data.js`,按文档结构调整即可。
- 本地预览:`python -m http.server 8642 --directory sabre-training-app`
- 修改图标后重新生成:`npm i && node icons.js`
